## Context

已有 JSON 任务数组，状态字段使用 pending/completed。入口是命令行，测试通过真实子进程观察 JSON 输出与重新读取结果。

## Goals / Non-Goals

**Goals:** 完成指定任务、持久化、重复操作稳定、失败保留原数据。

**Non-Goals:** 登录、多用户、并发写入、编辑/删除、云同步、进程强杀恢复。

## Decisions

- 沿用当前状态词，不引入 succeeded 或新枚举。
- 已完成时直接返回，避免重复写入；不存在时在写入前报错。
- 通过真实 CLI 测试可观察行为，预期来自需求；独立进程重新读取验证持久化。
- 不新增第三方 Python 依赖。

## Risks / Trade-offs

本地 JSON 适用于本教学范围，多进程写入可能丢失更新，明确排除。原子替换有助于减少部分写入，但并未验证断电后的耐久性。
