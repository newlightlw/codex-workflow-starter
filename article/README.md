# 配套公众号文章

- `wechat.md`：可编辑正文源文件。
- `wechat-copy.html`：下载后本地打开，分开复制标题、摘要、富文本正文；封面单独下载。
- `cover.png`：AI 生成的公众号封面。
- `images/`：5 张正文插画原始 PNG、放置说明与完整生成提示词。

v0.2.7 面向刚安装 Codex 的读者，标题与开篇聚焦第一个小功能。第 1 节增加 4 步上手路线和可调整的起手模板，再介绍组件、规则与 Skills；结尾回到亲手验收。资料链接在前部保留，实际案例作为后续补充。8 节正文、12 行组件表、5 处经验总结及 5 张配图保留，现有插画调整位置，匿名案例的验证结论不变。

HTML 是由 Markdown 制作的静态分发版，包含行内样式、内嵌图片和离线复制功能。正文配图可逐张下载；若公众号编辑器粘贴时缺图，请按图注上传。尚未验证公众号后台实际粘贴或发布。建议“阅读原文”指向本仓库。
