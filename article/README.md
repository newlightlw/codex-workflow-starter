# 配套公众号文章

- `wechat.md`：可编辑正文源文件。
- `wechat-copy.html`：下载后本地打开，分开复制标题、摘要、富文本正文；封面单独下载。
- `cover-beginners.png`：对应用户定稿标题的当前封面；生成提示词见 `cover-generation.md`。
- `cover.png`：保留的历史封面。
- `images/`：5 张正文插画原始 PNG、放置说明与完整生成提示词。

v0.2.10 在组件介绍后新增第 12 章“跟着我一起动手吧”，按六步介绍下载项目、生成练习、核对材料、tdd 实现、检查交付与接入已有项目。第 11 章保留 Taskbox 的用途与练习内容，具体操作集中在第 12 章。全篇共 12 个编号章节、1 个独立工具箱章节和 10 张阶段与作用卡片，保留故事开头、5 处经验总结、5 张配图和匿名案例。标题与封面采用作者定稿。

HTML 是由 Markdown 制作的静态分发版，包含行内样式、内嵌图片和离线复制功能。正文配图可逐张下载；若公众号编辑器粘贴时缺图，请按图注上传。尚未验证公众号后台实际粘贴或发布。建议“阅读原文”指向本仓库。
