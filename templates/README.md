# 按缺口选模板

已有规格、ADR、任务单、交接或测试记录时优先更新原文件，不为对齐目录而重复一份事实。

| 用途 | 模板 |
| --- | --- |
| 全局工作偏好 | [AGENTS.global.md](AGENTS.global.md)，选择性合并 |
| 项目交接 | [HANDOFF.md](HANDOFF.md) |
| 背景、目标、范围、约束、验收 | [TASK.md](../.agents/skills/codex-workflow/assets/TASK.md) |
| 当前状态与恢复入口 | [STATE.md](../.agents/skills/codex-workflow/assets/STATE.md) |
| 命令、环境、结果及未验证范围 | [VALIDATION.md](../.agents/skills/codex-workflow/assets/VALIDATION.md) |
| 项目 AGENTS 的精简入口 | [PROJECT-ENTRY.md](../.agents/skills/codex-workflow/assets/PROJECT-ENTRY.md) |

后三类工程记录随独立 Skill 一并分发，便于脱离 starter 使用。所有方括号内容都须替换为核实的项目事实；模板中的“未执行”不能直接改成“通过”。
