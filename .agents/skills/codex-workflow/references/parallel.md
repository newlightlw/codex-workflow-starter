# 并行边界

本参考只在用户要求并行，或其他适用指令明确授权时使用；它不自动启动子 Agent 或创建 worktree。

先判断任务是否有独立输入、交付物和完成标准。只读探索、测试缺口调查或独立审查通常较易拆分。依赖接口尚未确定、多个任务改同一文件或共用可变状态时，先串行明确边界。

每个子任务写清：目标、所需原始材料、可读/可写范围、依赖、输出格式、完成条件和负责人。主 Agent 负责整合、冲突处理、最终集成验证和报告；局部测试通过不能替代合并后的检查。

Worktree 隔离代码工作目录，不隔离数据库、端口、队列、共享文件、云账号或测试数据。开始并行写入前为这些实际资源明确独立名称与清理归属。涉及外部真实资源时仍按原授权执行。

已有适合的 checkout/worktree 优先复用。创建或删除 worktree 需要本轮相应授权；清理前确认成果已保存且无待保留改动，遵守客户端的工作区管理方式。工具不可用时说明限制并在单 Agent 内继续可独立完成的工作。
