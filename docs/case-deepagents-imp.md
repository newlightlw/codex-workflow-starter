# codex-workflow 在 deepagents_imp 中的连续两轮使用

记录版本：v0.2.2。证据整理截至 2026-11-13 20:36（Asia/Shanghai）。S2-05 已完成实现与隔离验证交付；S2-06 以下述首轮真实演练、后续只读核对和修复复核安排为准。本页来自作者私有项目会话、阶段报告和执行日志的摘要，不是公开 Taskbox 练习的成绩。

## 使用入口与连续性

作者先确认 `codex-workflow` 已安装并约定下一轮使用，随后两轮都只输入“继续开发”。S2-05 有主文件和恢复/审查参考的读取记录；S2-06 又读取了 Skill 主文件及相应参考，核对 S2-05 验收报告中的文件摘要并保存新一轮基线。

使用版本来自 v0.2.0；作者本地明确了自动触发描述、`allow_implicit_invocation: true` 和全局按需读取规则。工作流正文、参考和模板与发布版一致。

这证明在该项目、既有约定与配置下，用户无需每轮重新输入技能名，也能连续使用。两轮都发生在同一会话；没有据此验证全新会话的纯自动发现、跨会话恢复成功率或跨客户端表现。

## 使用反馈

- 上一阶段的学习说明、规格和验收报告成为下一阶段的入口，连续两轮无需重新描述完整背景。
- 既有约束与规则变更分别处理：已完成结果复用、未完成图续跑、金额预算与调用次数各自有明确条件。
- 实现、自动测试、真实模型运行、恢复成功和 Cloud 核验被分开记录；真实运行没通过时，保留调用、费用与失败事实。

这些行为同时受到项目原有规则、Skill 和用户授权约束，不能将全部效果单独归因于 Skill。没有时间对照实验、满意度评分或返工率统计，不提供量化效率结论。
