## 使用背景与入口

作者在已有 Deep Agents 工作台中接续 S2-05，目标是处理研究结果最终提交前中断后的复用，以及未知模型费用的保守对账。

用户先要求确认 `codex-workflow` 已安装并在下一轮使用。Codex 实际读取了其 `SKILL.md`；下一轮用户输入“继续开发”，Codex 明确使用该 Skill 接续任务，又读取了 `references/state-and-recovery.md` 和 `references/review-and-learning.md`。

这证明技能已在真实项目中被读取和使用，而不是仅完成安装。由于此前已有显式使用约定，它不能单独证明完全没有提示时的自动匹配率，也没有在本案例中验证跨会话恢复。

使用版本来自 v0.2.0；作者本地另明确了自动触发描述、`allow_implicit_invocation: true` 和全局按需读取规则。工作流正文、参考与模板与发布版一致。本案例描述这套本地配置的实际使用，不声称所有客户端或配置都有相同表现。

## 观察到的过程

1. 读取项目 AGENTS、阶段学习索引和现有恢复、结果记录、预算相关实现。
2. 修改前核对上一阶段报告中的文件摘要，并保存本轮前的基线。
3. 延续已有预算与调用上限；本轮按隔离故障测试推进，没有新增真实付费调用。
4. 实现结果复用和未知费用处理，增加或调整提交中断、取消、版本变化、重复操作与晚到结果等检查。
5. 新合同测试曾因漏导入 `Path` 在收集阶段失败，随后修复并重新运行；没有把这次失败计为通过。

这些行为同时受到项目既有规则和用户授权约束，不能将它们的全部效果单独归因于一个 Skill。
