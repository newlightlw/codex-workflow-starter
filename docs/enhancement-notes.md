# 工程增补依据与真实使用进展

本次参考用户提供的《Codex 高效使用技巧与工程实践指南》，把其中有助于复用的工程方法改写为手册、模板与项目接入能力。该材料没有提供可核对的作者和许可证，本仓库不打包或原样发布其全文，也不把材料中的操作示例当作实际执行授权。

## 参考内容如何落地

| 主题 | 本次结果 | 取舍 |
| --- | --- | --- |
| 先探索再实施 | 工程手册、codex-workflow 接入分支 | 明确任务仍自主完成，不给所有任务增加确认门槛 |
| 工程 Issue | TASK 模板与 Taskbox 完整例子 | 可本地使用，不要求建立外部 Issue |
| 分层 AGENTS | 项目入口合并模板 | 精简指令，详细设计按条件引用 |
| 实施—测试—审查—报告 | 审查参考与 VALIDATION 模板 | 区分自审与独立审查，不把数量当质量 |
| Skills 沉淀 | 新增一个独立 codex-workflow | 沿用 6 个已有专项 Skills，不批量造重复技能 |
| 跨会话状态 | STATE、恢复步骤 | 优先复用现有 Spec/ADR/OpenSpec，不复制第二份基线 |
| Subagents 与 worktree | 并行边界和手动示例 | 需明确授权，隔离共享资源，本次未运行并行实验 |
| 可执行环境 | 复用真实测试入口，新增接入工具的测试 | 不生成无对应工具的 lint/typecheck 空脚本 |
| CLI 与权限 | 独立命令参考与官方链接 | 记录本机版本，区分参数核对和模型实测 |
| 复盘与持续改进 | 原因到测试/规则/脚本/规格的映射 | 先看复发价值，不自动写长期或共享记忆 |
| 个人后续使用 | 预览优先、拒绝覆盖的项目接入工具 | 只安装自包含 Skill，保留既有 AGENTS 和全局设置 |

## 文章中的事实层次

- 既有实践：全局偏好、文档/OpenSpec、karpathy-guidelines、grill-me、tdd、project-testing，以及历史项目例子。
- 本次新增交付：工程手册、codex-workflow、模板与接入工具。
- 已确认的真实使用：v0.2.1 记录 S2-05 开发中的定向检查；v0.2.2 更新为 S2-05 的 416 项阶段验证与 S2-06 的 428 项回归、真实演练未通过及排查中的记录，见[案例及反馈](case-deepagents-imp.md)。
- 可选进阶方法：多 Agent/worktree、CLI 自动化，说明适用条件并核对文档，不写成作者已经长期亲测的全部习惯。

核心 Taskbox 业务 R1–R6 未扩展。新增代码只负责把独立 Skill 接入已有项目；行为依据见 `adoption.md` 的 A1–A4。

v0.2.1 与 v0.2.2 只更新文章和案例文档，未改 Skill、安装脚本或教学业务实现。实际使用的是用户级 Skill，不代表已经在真实项目执行 `adopt_workflow.py`，也不代表所有附带模板都已落地。
